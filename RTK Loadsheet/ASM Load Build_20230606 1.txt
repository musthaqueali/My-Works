Purpose
The purpose of this procedure is to provide the guidelines for creating the APM Connect Data Loader that will be used to import the Asset Strategy Data to the ASM module. This data will be implemented to Asset Strategy Implementation and then packaged before sending to SAP.
Objective
This procedure instructs on the proper steps for aggregating the required fields needed to populate the Strategies, Action, Risks, and Mitigations of the template.

2.0 Populate Strategies
Strategies is the first worksheet that will be created as part of the ASM Loader. This tab will create Strategies records within ASM. The strategies identified and created in this tab will be referenced in each subsequent tab.
Begin filling in the tab by column, using the resources available and the techniques/processes suggested below.

[TABLE ROW] Term | Definition
[TABLE ROW] Functional Location | Organizational unit within the business hierarchy that structures the maintenance objects according to functional, process-related, or spatial criteria. The Functional Location represents the physical place at which a maintenance task is to be performed.
[TABLE ROW] Equipment | An individual object in the system that is maintained independently. Equipment can be stored at different Functional Locations. For the purposes of this project, each fixed asset (Tank, Pressure Vessel, Piping Circuit, PSV) will have its own Equipment record.
[TABLE ROW] Strategy | A defined plan for an asset or system that identifies both the Risks (failure modes) and Actions (physical actions) to manage or mitigate the Risks.
