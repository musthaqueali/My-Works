DELIVERABLE REQUIREMENT: TM Datamining and Loading
CLIENT: RTK
SITE: RTK
PROJECT: TM Full Implementation
REVISION: 1.0
Purpose
Pinnacle will use the process and methodology documented in the deliverable requirement TM Datamining & Loading to:
Datamine the necessary fields required for the Thickness Monitoring (TM) Module to manage inspections, monitor asset health, and ensure inspection compliance in APM.
Develop load sheets for fixed equipment and piping circuits which will provide a baseline reference at the time of the implementation and may be used to identify changes made during Evergreening of the MI Inspection Program
Import load sheets into the APM TM Module
TM Datamining & Loading
Key Aspects & Features
Mechanical Data Mining (Equipment and Piping): Pinnacle will collect asset design and construction information from gathered asset documentation. Pinnacle will datamine piping mechanical data using RTK piping standards/specifications.
Fixed Equipment and Piping Circuit APM Load: Pinnacle will develop load sheets for equipment and piping circuits to load into APM.
GE APM Thickness Monitoring (TM) Module
Pinnacle will datamine existing historical TML data for equipment and piping circuits, and load to corresponding TMLs in APM.
Out of Scope
APM fields not listed as required fields in Section E and Section F and their dependents, will not be datamined and loaded.
Equipment and Units not listed as in-scope on the MALs will not have their TMLs datamined.
TMLS that cannot be correlated using an equipment drawing will not be datamined.
Final Format
Datamined load sheets will be loaded into the GE APM Thickness Monitoring (TM) Module
Assumptions
Pinnacle assumes that accurate line specification sheets are available for piping-datamining.
Pinnacle will only need to datamine the appropriate data as detailed in Section E and Section F of this deliverable requirements document.
Pinnacle assumes that all asset documentation is accurate and available to the project team.
Pinnacle is not calculating or assessing for fitness for services (FFS).
Pinnacle is not performing T-min calculations internal or external to the APM system as part of this scope of work for pressure or structural T-min analysis.
Minimum Structural T-min for piping will follow API 574 Table 7 for all pipe sizes. T-min for pipe sizes not included in API 574 Table 7 will be modeled after the largest pipe size in Table 7. This will be used for all piping materials at all temperatures.
All assets are built to ASME VIII, ASME B31.3 or API 650 codes.
Any non-required field will not be modified.
Pinnacle will provide a list of TML/Circuit data gaps for RTK to vet gaps and fill in necessary data for Pinnacle to load if desired.
APM piping formula A will be loaded for the purpose of T-min calculations for piping because it is the most consistent.

1. Below 0.1, use 0.1
2. Above 0.1, use calc Tmin on PV calc sheet.

Piping: 
1. API 574 Table Structural Alert (left side of table) is lowest value TML can be
2. Tmin not provided, document in Data Gap Log. 
Table 7 in API 574 will be applied to all piping materials at all temperatures.

Tanks: 
Below 0.1, use 0.1
Above 0.1, use calc Tmin [Internal Inspection docs have values for Min thickness per Shell Course and a lot of cases even the roof]
Tmin not provided, document in Data Gap Log. 
For equipment & ASTs with nominal below 0.1, utilize nominal for the Tmin.
