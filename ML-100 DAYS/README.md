# The CampusX Machine Learning & AI Library

An interactive, high-performance broadsheet knowledge platform designed after **[musthaque.netlify.app](https://musthaque.netlify.app)**, hosting all 10 major CampusX lecture courses and reference notes across **6,027 folios and 9,092 topics**.

---

## 📚 The 10 Course Volumes in Your Library

1. **VOL. 01 — 100 Days of Machine Learning** (2,434 pages • 6,089 topics)  
   Classical ML algorithms, mathematical proofs, ensemble methods (AdaBoost, Random Forest, Gradient Boost), optimization, and end-to-end MLOps lifecycle.
2. **VOL. 02 — 100 Days of Deep Learning** (1,125 pages • 287 topics)  
   Perceptrons, backpropagation mathematics, CNNs, RNNs, LSTMs, and modern Transformer self-attention mechanisms.
3. **VOL. 03 — Generative AI with LangChain** (461 pages • 526 topics)  
   Prompt engineering, LCEL syntax, Chains, Memory, Output Parsers, Vector Databases, and Retrieval-Augmented Generation (RAG).
4. **VOL. 04 — Agentic AI using LangGraph** (531 pages • 478 topics)  
   Stateful agentic architectures: graph states, nodes, conditional edges, multi-agent collaboration, memory persistence, and human-in-the-loop workflows.
5. **VOL. 05 — PyTorch Complete Course** (304 pages • Structured Chapters)  
   Tensor operations, autograd dynamic graphs, custom datasets/dataloaders, model training loops, and deployment.
6. **VOL. 06 — FastAPI for Machine Learning** (365 pages • Structured Chapters)  
   Pydantic schemas, dependency injection, asynchronous endpoints, Docker containerization, and REST API deployment.
7. **VOL. 07 — Model Context Protocol (MCP)** (244 pages • Structured Chapters)  
   Anthropic's open Model Context Protocol: server-client architecture, tool registration, prompt templates, and IDE integration.
8. **VOL. 08 — NLP Full Course & Projects** (222 pages • Structured Chapters)  
   Tokenization, TF-IDF, Word2Vec, semantic similarity, and industrial Quora Duplicate Question Pairs project.
9. **VOL. 09 — Claude Code Complete Guide** (149 pages • 377 topics)  
   Agentic coding workflows, CLI commands, context optimization, subagents, and automated refactoring with Claude Code.
10. **VOL. 10 — LLM Evaluation Notes** (192 pages • 408 topics)  
    RAG evaluation, hallucination detection, Ragas, TruLens, LLM-as-a-judge, and CI/CD evaluation pipelines.

## ⚡ Key Features

- **Library Catalog Landing Page**: Broadsheet course blocks with category filters, reading progress, and global topic search across all 9,000+ topics.
- **Direct Continuous Scrolling**: Smooth, uninterrupted vertical scroll desk across every folio of the selected course.
- **Zero Loading Delay (0.000s Navigation)**: Clicking any chapter, section, or subtopic in the Index immediately glides to that exact page without reloading.
- **Course Switcher**: Switch between any of the 10 courses with a single click right from the reader top bar.
- **Reading Progress**: Automatically tracks and remembers your last read page independently for each of the 10 courses!
- **Broadsheet / Warm Parchment Aesthetics**: Designed with the warm broadsheet palette and typography of [musthaque.netlify.app](https://musthaque.netlify.app).

## 🚀 How to Launch

Simply double-click **`start_website.bat`**.

It automatically launches the high-speed local streaming server (`serve.py`) with byte-range requests enabled and opens the library catalog directly in your browser at `http://localhost:8000/index.html`.
